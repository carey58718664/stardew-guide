🐟 统一物品结构 · 鱼类样例

把分散的"物品库名单"和"场景结构化数据"合并成一份权威数据，物品库按「类型 + 季节」投影。这是验证用，不是成品。

统一数据结构（每个物品一条）： 
{
  name: "鲶鱼",            // 权威显示名（统一译名后）
  en:   "Catfish",         // 英文 = 图标文件名（Catfish.png）
  cat:  "fish",            // 物品库分类
  owner:"library",         // 归属：library=物品库 / cart=购物车
  seasons: ["spring","summer","fall"],  // 季节；["special"]=不分季节（地点性）
  place: "河流",           // 场景用的元数据（地点/时间等都挂这）
  bundle: true,            // 是否收集包需要
  legend: false            // 是否鱼王
}
一份数据同时喂三处：① 物品库按 cat+seasons 分组（下方效果）；② 购物车按 owner=cart 筛；③ 场景集只读 place/time 等做攻略，不再自存物品清单。
样例里已经做掉的清理：
• 删掉物品库 7 个查无对应的错条（草鱼/彩虹鱼/绿松石鱼/玻璃鱼/铁头鱼/午夜鳗/深海鱼）。
• 统一译名（如 红鲫鱼→红鲻鱼）。
• 补齐 5 个鱼王（👑）。
• ⚠️ 标记的 4 条要你拍板：「鲷鱼」(special河流收集包，疑误)、「虾虎鱼」「冰柱鱼」(英文待核)、「鬼鱼/幽灵鱼」其实是两条不同的鱼(Ghostfish矿洞 / Spook Fish夜市)，译名要定。
